# 商业模式

## 一、产品定位

**契约精神**是一款面向个人与小型组织的契约管理与承诺追踪工具，定位介于：

- **轻量级**：待办清单 / 习惯追踪（如 Todoist、Habitica）
- **正式级**：电子签约平台（如 DocuSign、法大大）

填补"口头承诺 vs 正式合同"之间的空白。

---

## 二、目标用户

| 用户群体 | 需求 | 使用场景 |
|----------|------|----------|
| 个人用户 | 记录自我承诺、追踪习惯 | 读书计划、健身目标、学习打卡 |
| 朋友/伴侣 | 双方约定 | 合租协议、借款记录、共同目标 |
| 自由职业者 | 与客户建立简单合作约定 | 项目范围确认、付款计划 |
| 小团队 | 内部协作约定 | 任务分工、deadline 承诺 |

---

## 三、核心价值

| 价值 | 说明 |
|------|------|
| **记录** | 口头承诺文字化，避免遗忘或扯皮 |
| **追踪** | 实时查看履约进度，到期提醒 |
| **量化** | 信任分让守信可见，建立个人信用档案 |
| **低成本** | 比正式合同简单，比口头承诺可靠 |

---

## 四、盈利模式

### 免费层
- 创建最多 10 份活跃契约
- 基础信任评分
- 个人承诺追踪

### 付费层（规划中）
- 无限契约与承诺
- 高级数据分析（信任分趋势、履约报告）
- PDF 导出契约
- 自定义品牌（团队版）
- 优先支持

### 增值服务
- 契约模板市场
- 电子存证（区块链哈希存证）
- API 接入（企业版）

## 五、竞品对比

| 维度 | 契约精神 | Todoist | DocuSign | Notion |

## 六、市场策略

### 初期
- 个人用户口碑传播
- 开源社区推广（GitHub）
- 产品导向的冷启动

### 增长期
- 模板市场吸引垂直场景用户
- 团队协作功能推动组织采用
- 信任分体系的网络效应

---

## 七、风险与应对

| 风险 | 应对 |
|------|------|
| 用户履约数据隐私 | 数据加密 + 用户控制可见性 |
| 与正式合同混淆 | 明确"社交约定"定位，不提供法律建议 |
| 信任分被滥用 | 透明评分算法，支持申诉 |
| 用户留存 | 通过习惯养成和承诺完成的正向反馈 |
