# 兑一兑 · 反馈窗口开放计划（推广 + 征集）

> **状态：** 待命 → **2026-08-05 起正式开窗**（公网上线日）  
> **窗口：** 2026-08-05 → 2026-08-18（第 1 波，约 2 周）  
> **目标：** 首批 **20～30** 人真实使用主闭环，并留下可行动反馈  
> **上线日历：** [launch-2026-08-05.md](../launch-2026-08-05.md)  
> **运营：** [feedback-ops](./README.md) 每周五出总负责人简报  
> **不做：** 付费获客、公开大投放、盈利话术、App 商店前置

口号：对自己守信，才能对他人守信。 · 做到了，兑一兑。

---

## 1. 为什么现在开窗

| 已具备 | 仍受限 |
|--------|--------|
| 产品内 `/feedback`、头像菜单、页脚入口 | 公网域名/HTTPS 若未就绪，先用可访问的 Staging/内测地址 |
| 主闭环：注册 → 我的承诺 → 兑奖；监督路径可用 | 邮件重置可能仍是临时方案 |
| digest → `*-pm-brief.md` 给总负责人 | 真实用户样本尚少 |

**开窗定义：** 主动邀请目标用户进来用，并明确「我们正在收初版意见」——不是静默上线等自然流量。

---

## 2. 第 1 波推广计划（邀请制）

### 2.1 人群（优先顺序）

| 优先级 | 人群 | 人数目标 | 为何 |
|--------|------|----------|------|
| A | 熟人里「爱立 flag / 自律困难」者 | 8～12 | 转化快、愿说真话 |
| B | 需要「有人盯着」的同事/同学 | 6～8 | 验证见证人/监督路径 |
| C | 产品/设计朋友（短评体验） | 4～6 | 抓理解成本与文案 |

合计：**20～30**。超过 50 人再开第 2 波。

### 2.2 渠道（只做免费、可控）

| 渠道 | 动作 | 话术要点 |
|------|------|----------|
| 微信私聊 / 群 | 发邀请短链 + 一句任务 | 见 §4 |
| 飞书/企微私聊 | 同左 | 同左 |
| 朋友圈（可选） | 1 条「内测征意见」 | 不写融资/会员；强调反馈 |

**禁止：** 付费投放、水军、夸大「已上线全网」若实际仍是内测地址。

### 2.3 邀请时给用户的「最小任务」（3 分钟）

1. 注册登录  
2. 创建 **一条带奖励的「我的」承诺**  
3. （可选）邀请 1 位见证人，或建一条「他人」约定  
4. 打开 **意见反馈**，写一句：哪里顺 / 哪里卡  

---

## 3. 反馈征集计划

### 3.1 产品窗口（已落地）

- 首页展示「反馈窗口开放」条，链到 `/feedback`  
- `/feedback` 页标明窗口期与希望听到的问题  
- 页脚强化「初版征意见」  

### 3.2 我们主动问什么（结构化）

用户可自由写；邀请话术里建议他们回答至少一项：

1. 注册后 **1 分钟内** 是否知道下一步？  
2. 「奖励必填 / 兑奖」是否说得通？  
3. 「我的 / 他人（监督）」是否分得清？  
4. 最想砍掉或最想补的一点？  

### 3.3 运营节奏

| 日 | 动作 |
|----|------|
| D0（开窗日） | 发出 A 类 8～12 人邀请；确认反馈入口可点 |
| D2 | 未留反馈者轻触达一次；修 P0 阻断 |
| D7 | 汇总半程：条数、主题；必要时补邀 B/C |
| **每周五** | `./scripts/feedback-digest.sh` → 简报交给总负责人 |
| D14（关窗或续波） | 复盘指标；决定续窗 2 周或收窄 |

### 3.4 成功标准（第 1 波）

| 指标 | 达标线 |
|------|--------|
| 受邀并注册 | ≥ 15 |
| 创建带奖励承诺 | ≥ 10 |
| 站内反馈条数 | ≥ 12（含追问） |
| 有「主闭环卡点」类反馈 | ≥ 3 条可转任务 |
| P0 阻断 | 发现后 **24h 内** 标进简报 |

对照产品北极星（[初版.md §3](../../versions/初版.md)）：创建率、兑奖率、见证率、D7——样本小先看方向，不据此砍商业化（本来就没有）。

## 6. 风险与底线

| 风险 | 应对 |
|------|------|
| 没人反馈 | D2 必触达；降低任务到「只注册+一句话」 |
| 反馈全是要新功能 | 归入 P2/终极版；Must 只认主闭环与理解成本 |
| 地址不稳定 | 开窗前用 checklist 冒烟；变更 URL 同步名单 |
| 隐私 | 名单不入库；raw JSON 不公开 |
