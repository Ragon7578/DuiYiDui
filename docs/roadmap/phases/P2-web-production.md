# P2 · Web 生产就绪

| 项 | 内容 |
|----|------|
| **周期** | 6～8 周（与 P1 后半重叠；紧凑约 4 周） |
| **累计月末** | 约 4.5 |
| **关口** | 公网 Staging/预发 Web 稳定跑通核心故事；API 契约冻结（如 `/api/v1`） |
| **里程碑** | **M2 Web 公测** |

---

## 阶段目标

试验版 Web 升级为可邀请制公测的生产前端：体验、性能、安全、运营页与发布链路齐备。  
**同时落实利基定位：** 首屏与创建路径符合 [design.md](../../design.md)（奖励突出、待兑现可发现、1 人见证轻路径）。

---

## 工作拆解

| 模块 | 工作项 | 周期（周） |
|------|--------|------------|
| **体验 / 定位** | 空态文案去 Todo 感；注册后引导首目标；待兑现入口；见证人建议邀 1 人 | 2 |
| **埋点** | 创建（奖励/见证）、达成、兑奖、邀请见证、D1/D7 | 含上 |
| **性能** | 首屏、列表分页、缓存策略 | 1～2 |
| **安全** | XSS/CSRF 面、CSP、依赖审计 | 1 |
| **运营页** | 隐私政策、用户协议、关于与反馈；价值主张一句话 | 1 |
| **发布** | 前端 CI/CD、预发域名、回滚 | 1 |
| **灰度** | 邀请制或功能开关 | 1 |

---

## 建议并行关系

- P1 W5 起即可开 Web 体验与运营页；契约冻结点与 P1 OpenAPI 对齐。  
- AI / 语音创建：V1 可保留 Web-only，不阻塞公测。  
- 押金 / 徽章 / **任何盈利 UI**：**本阶段不做**（终极版另册）。

---

## 验收清单

- [ ] 外网邀请用户可完成「建目标（含奖励）→ 兑奖」  
- [ ] 首页存在「待兑现」或等价行动位  
- [ ] 设计反模式自检通过（三人评审：不像 Todo）  
- [ ] 关键漏斗埋点可出数（为 M2.5 准备）  
- [ ] 隐私政策 / 用户协议可访问  
- [ ] 预发一键部署与回滚演练通过  
- [ ] 与 API 的版本契约已冻结并记录  
- [ ] M2 评审通过
