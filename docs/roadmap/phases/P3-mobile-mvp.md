## 阶段目标

Android / iOS 对齐 **初版基本能力**：账号、首页、目标闭环（含兑奖）、见证人轻路径、契约基础、通知、我的。复杂契约编辑、AI 语音标为 Should，可裁剪。

**前置建议：** 尽量在 [M2.5 使用关口](../README.md) 达标后再扩大双端打磨；未达标则只做「核心路径可跑」的最小包。盈利与终极版功能不进本阶段。
