# Agent 05 · 反馈迭代（Sprint 05+）

| 项 | 内容 |
|----|------|
| **分支** | `cursor/feedback-iter-c614`（每轮可新分支） |

## 目标

按用户反馈改**主路径**（激活、兑奖、见证），不上盈利、不堆终极版。

## 每轮 Must

- [ ] 拉反馈：`GET /api/feedback` + 周报 Top 问题
- [ ] 对照 [初版 §3 指标](../../versions/初版.md)：7 日建目标、兑奖率、见证率、D7
- [ ] 从 Top 问题选 1～3 条进 Sprint Must，改代码或文案
- [ ] `npm run build` + 相关路径手测
- [ ] `progress/YYYY-Www.md` 含反馈摘要与改动

## 不做

- 会员、押金、品牌券
- 以 App 挡 Web 迭代
