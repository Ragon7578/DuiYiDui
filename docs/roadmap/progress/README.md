# 每周开发进度

> 执行层：每周一份，记录**实际进度**，不替代迭代计划。

---

## 规则

1. 文件名：`YYYY-Www.md`（ISO 周，如 `2026-W30.md`）。  
2. 建议周五写；未完成项必须写清是否滚入下周。  
3. 范围变更、选型变化、阻塞，必须出现在「偏差 / 风险」。  
4. 模板：[_template.md](./_template.md)。
