# F3 · 反馈上线值班约定

| 项 | 内容 |
|----|------|
| **版本** | 初版公网收反馈 |
| **节奏** | 上线当周启用 |

## 谁看反馈

| 角色 | 职责 |
|------|------|
| **产品值班** | 每日看 `GET /api/feedback` 或产品内新反馈 |
| **技术值班** | 看 API 日志、健康检查、备份是否成功 |

填写实际负责人（示例）：

- 产品值班：________（邮箱 / 微信）  
- 技术值班：________  

## 多久回一次

| 类型 | SLA |
|------|-----|
| 反馈表单 | **工作日 48 小时内**首次回复 |
| 密码重置协助 | **工作日 48 小时内**（临时方案期间） |
| 汇总 | **每周五**写入 [progress 周报](../progress/) |

## 怎么拉反馈

```bash
curl -s "$API_URL/api/feedback?limit=50" \
  -H "X-Feedback-Admin-Key: $FEEDBACK_ADMIN_KEY"
```

## 首批邀请

- 目标 **≥20 人**（熟人 + 目标人群）  
- 告知：注册链接 + 邀请码（若开启 `REGISTRATION_INVITE_CODE`）+ 「我的 / 页脚 → 意见反馈」
