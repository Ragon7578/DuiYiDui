## 一句话介绍

**契约精神**是一款以 **目标达成** 和 **自我奖励** 为核心的承诺管理工具。

把你随口说过的「做到了就奖励自己」，认真记下来、追下去，并真正兑现金。

---

## 我们解决什么问题

你一定听过这些话：

- 「如果我考上驾照，就给自己买个 Switch」
- 「瘦到 60 公斤，就奖励自己一个包」
- 「项目做完就去旅行」
- 「今年一定读完 20 本书」

**然后呢？** 绝大多数承诺不了了之。

不是因为做不到，而是因为：

| 问题 | 结果 |
|------|------|
| 承诺太随意 | 说出口没有成本，不当回事 |
| 没有记录 | 说过就忘 |
| 没有追踪 | 达成那天，奖励的承诺早已被遗忘 |
| 没有监督 | 没人要求你对自己守信 |

初衷很简单：**对自己承诺过的事，应该有一个地方记下来，然后真正做到。**

## 产品是什么

不是待办清单，也不是正式电子合同。

它填补中间地带：

```
口头承诺  ←——【契约精神】——→  正式合同
   太轻                          太重
```

你设定一个目标，约定达成后的奖励，然后追踪进度：

- **做到了** → 奖励是你的  
- **做不到** → 承诺有据可查，赖不掉  

定位：面向个人与小型协作的 **承诺追踪与契约管理** 工具。

---

## 核心理念

1. **对自己诚实** — 每一个承诺都写清楚  
2. **用奖励激励履约** — 想清楚「做到了能得到什么」  
3. **让违约有记录** — 不是羞辱，而是留下痕迹  
4. **信任可视化** — 履约记录就是信用档案  

成长路径：

```
对自己守信 → 对他人守信 → 建立社会信任
```

承诺 + 奖励的正循环：

| 要素 | 作用 |
|------|------|
| 目标 | 明确你要做什么 |
| 奖励 | 给兑现承诺一个理由 |
| 记录 | 让承诺不可轻易撤销 |
| 追踪 | 随时看到进度 |
| 兑现 | 完成目标，获得奖励 |

原则：**轻量、真实、不装** — 不需要复杂法律条款，只需要对自己诚实。

---

## 主流程

```
设定目标 → 绑定奖励 → 追踪进度 → 达成 → 兑现奖励
                              ↘ 未达成 → 记录在案
```

这是用户最常用的一条路。页面与功能都围绕它展开。

## 主要功能与页面

### 页面一览

| 页面 | 做什么 |
|------|--------|
| 登录 / 注册 | 用用户名开账号（门槛低） |
| 首页 | 信任分、进行中的目标与契约 |
| 目标 | 对自己的承诺：进度、奖励、兑现 |
| 契约 | 对他人的约定与条款 |
| 承诺 | 轻量记下想守住的事 |
| 创建 | 新建目标或契约（可语音 / 智能填写） |
| 我的 | 履约统计、信任分、补充邮箱手机 |
| 通知 | 进度、见证、达成等提醒 |

### 目标（对自己）

每个目标通常包含：要做什么、达成后奖励什么（核心）、可选截止日期与见证人。

状态：`进行中 → 已达成 → 奖励已兑现`，或 `已放弃`。

**示例：** 小明「连续跑步 30 天 → 买一双新跑鞋」→ 更新进度 → 达成 → 兑现 → 信任分上升。

### 契约（对他人）

| | 目标 | 契约 |
|--|------|------|
| 对象 | 对自己 | 对他人 |
| 约束 | 自我约束 | 社交约束 |
| 奖励 | 自我奖励 | 双方约定 |
| 监督 | 自己 / 见证人 | 参与方互相监督 |

状态：草稿 → 进行中 → 完成 / 违约 / 取消。

**示例：** 小红帮小李做设计稿，小李请吃饭——写成契约，条款逐条勾掉。

### 信任分

信任分是「守信名片」：履约加分，放弃 / 违约减分。在首页与「我的」可见。长期趋势比单次分数更重要。

## 操作说明

### 开始使用

1. 打开产品（本地一般为 http://localhost:3000）  
2. **注册**：只需用户名 + 密码  
3. **登录**后即可使用  

之后可在「我的」补充邮箱、手机。绑定邮箱后，可通过邮箱找回密码。

### 创建并完成一个目标

1. 进入 **创建** → 选择「目标」  
2. 填写要做到什么、**达成后奖励自己什么**（必填）  
3. 可选：截止日期、见证人  
4. 在 **目标** 里更新进度  
5. 达成后标记完成，并标记 **奖励已兑现**  

### 与他人立一份契约

1. 进入 **创建** → 选择「契约」  
2. 填写标题、约定、参与方  
3. 在详情中更新条款状态  
4. 完成或记录违约  

### 常见问题

**注册要不要填邮箱？**  
不需要。登录后在「我的」绑定即可。

**忘记密码怎么办？**  
登录页「忘记密码」，用已绑定邮箱重置。

**目标和契约有什么区别？**  
目标对自己、常带自我奖励；契约对他人、双方约定。

## 目标用户与价值

| 用户 | 场景 |
|------|------|
| 个人 | 读书、健身、学习等自我承诺 |
| 朋友 / 伴侣 | 共同目标、轻量约定 |
| 自由职业者 | 与客户的简单合作约定 |
| 小团队 | 分工与 deadline 承诺 |

| 价值 | 说明 |
|------|------|
| 记录 | 口头承诺文字化 |
| 追踪 | 看到进度与到期情况 |
| 量化 | 信任分让守信可见 |
| 低成本 | 比正式合同简单，比口头承诺可靠 |

商业上采用免费层 + 付费增强（规划中）的路径；细节随产品阶段调整，不以本文为合同。

## 和常见工具的区别

| | 契约精神 | 待办清单 | 电子签约 |
|--|----------|----------|----------|
| 重心 | 承诺与兑现 | 任务打勾 | 法律效力 |
| 奖励 | 核心设计 | 通常没有 | 通常没有 |
| 信任分 | 有 | 无 | 无 |
| 学习成本 | 低 | 低 | 偏高 |
| 适合谁 | 想对自己说到做到的人 | 管日程的人 | 要正式签约的人 |

相对 Todoist：「我需要做什么」vs「我们约定了什么 / 我答应奖励自己什么」。  
相对 DocuSign：解决「日常好用的约定」，不解决「法律上有效」。  
相对 Notion：开箱即用的承诺结构，不必从空白页搭模板。

```
                   正式 / 法律效力
                        │
                   DocuSign ●
                        │
    个人 ───────────────┼────────────── 组织
                        │
         契约精神 ●      │
                        │
                   Todoist ●
                        │
                   非正式 / 轻量
```
