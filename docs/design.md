# UI/UX 设计规范

> 以 `apps/web` 当前实现为准（墨色印章风），旧「黑白 + Geist」描述已废弃。

## 一、设计理念

| 原则 | 说明 |
|------|------|
| 信任感 | 稳重纸感背景 + 清晰层级，少喧闹装饰 |
| 品牌优先 | 「契约精神」为展示字体主角；英文副标 Say & Done |
| 状态可见 | Badge / 色块即时表达进行中、达成、违约等 |
| 奖励突出 | 创建目标时奖励字段为心理设计核心 |

## 二、设计 Token（`globals.css`）

| Token | 色值（约） | 用途 |
|-------|------------|------|
| `--ink` | `#0c0f14` | 主文字、主按钮底 |
| `--paper` / `--paper-deep` | `#f3f5f8` / `#e6eaef` | 背景、浅底 |
| `--seal` / `--seal-soft` | `#c81e1e` / `#fde8e8` | 强调、必填、危险弱提示 |
| `--line` | `#c8d0db` | 边框分割 |
| `--muted` | `#5c6678` | 次要文字 |
| `--ok` / `--ok-soft` | 绿系 | 成功、履行 |
| `--warn` / `--info` | 黄 / 蓝系 | 警告、信息 |

背景：浅色纸感 + 微弱径向渐变与噪点，非纯扁平单色。

## 三、字体

| 角色 | 字体 | CSS |
|------|------|-----|
| 展示 / 品牌 / 大标题 | Noto Serif SC | `.font-display` |
| 正文 / UI | Outfit | `body` / `--font-body` |

**不要**再使用 Geist 作为规范字体。

## 四、组件约定

| 组件 | 约定 |
|------|------|
| `FormLabel` | 必填项显示印章色 `*` |
| `Badge` | 语义色映射状态 |
| `Card` | 内容分区；非交互列表避免过度「卡片堆」 |
| 主按钮 | `.btn-primary`（墨底） |
| 输入 | `.input-field` |

## 五、导航

登录后主导航：

首页 · 目标 · 契约 · 创建 · 通知 · 我的  

- 品牌「契约精神」点回首页  
- 通知可显示未读数  
- 未登录：登录 / 注册入口  

`/pledges` 有路由，**默认不进主导航**。

## 六、关键页面要点

### 认证

- 注册：仅用户名 + 密码 + 确认密码  
- 登录：用户名 + 密码；链到忘记密码  
- 忘记密码：邮箱；试验环境可展示重置链接  
- 重置密码：token 查询参数  

### 首页

欢迎语、信任分、统计、进行中目标 / 契约摘要。

### 目标

列表 + 进度；达成后引导兑现奖励；可涉及见证人。

### 创建

目标 / 契约 Tab；语音输入与智能填表区域；奖励必填（目标模式）。

### 我的

可编辑邮箱、手机、简介；只读登录名；履约率可视化与目标记录。

## 七、动效

- 入场：`animate-rise` 等轻微上浮  
- 导航激活：印章色下划线  
- 避免过量 glow / 紫渐变（与产品视觉方向不符）  

## 八、响应式

- 内容最大宽约 `max-w-5xl` 居中  
- 小屏导航可横向压缩字号；后续可考虑底栏
