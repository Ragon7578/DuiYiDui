# 终极版（功能全集 · 再谈盈利）

| 项 | 内容 |
|----|------|
| **版本名** | 终极版 / Ultimate |
| **目标** | 介绍与规划中的**各功能完全实现**；形成完整产品形态 |
| **前置** | [初版](./初版.md) 已能稳定吸引目标用户使用（使用指标可接受） |
| **盈利** | **在功能补齐的规划里再考虑**；不倒逼初版 |
| **来源** | [兑一兑.md 下篇](../兑一兑.md) 规划全文 + 本文清单 |
| **排期** | 初版里程碑之后滚动；可用 [P6 backlog](../roadmap/phases/P6-product-backlog.md) 拆 Sprint |

---

## 1. 原则

1. **先功能完整，后盈利设计落地。** 会员 / 品牌券 / 押金等可以写在终极版蓝图里，但实现顺序上优先「用户能用到的能力」，付费与投放后置或并行评估。  
2. **不得把终极版未决盈利方案写进初版 Must。**  
3. 合规敏感项（真金、公益资金、支付）必须单独关口，不可与普通功能同批「顺便上」。

---

## 2. 功能全集（相对初版的增量）

以下在初版基本能力之上补齐；细项以介绍下篇为准，落地前可再裁剪优先级。

### 2.1 目标与承诺增强

- 进度类型：百分比 / 打卡 / 里程碑等完善  
- 目标分类与模板库（健身 / 学习 / 习惯等）  
- 轻量承诺（Pledge）产品化入口（若仍需要）  
- 语音 / AI 创建多端增强  

### 2.2 契约与见证加深

- 单人 / 双人 / 多人契约完整流程  
- 见证人验收权、留言鼓励、名额扩展  
- 连坐（可选，慎用）  
- 公开目标围观（若做，需隐私开关）  

### 2.3 信用与游戏化

- 信任分扩展规则与等级 Lv、权益  
- 积分、签到、连续更新奖励  
- 成就徽章（可先轻量，商城后置）  
- 成就海报 / 分享图（利于传播）  

### 2.4 约束与公益（规划项）

- 虚拟押金（积分冻结 / 返还 / 扣除）  
- 公益捐赠池展示与对接（须合规）  

### 2.5 平台与体验

- 三端体验完全对齐与高级设置  
- 报表导出、皮肤 / 封面等个性化  
- 企业 / 团队空间（更远期，可单列）  

---

## 3. 盈利考虑（仅终极版）

> 初版**不实现**下列任何实际盈利点。本节供终极版阶段产品与商务使用。

| 模式 | 说明 | 建议时机 |
|------|------|----------|
| 免费 + 会员订阅 | 扩见证人名额、自建模板、皮肤、报表等 | 功能主体可用且有稳定活跃后再做 |
| 品牌合作券 | 达成发放品牌优惠 | 有一定 DAU 再谈 BD |
| 公益相关展示 | 与违约/押金叙事结合（非必盈利） | 法务与资金合规通过后 |
| 企业版 | 团队契约与管理 | 更远期 |

**注意：** 盈利是终极版的**专题**，不是衡量初版是否成功的标准。初版成功 = 相关用户愿意用。

---

## 4. 建议实现顺序（终极版内部）

```
A. 降摩擦与传播     模板库、成就海报、见证加深
B. 信用与轻游戏化   等级、轻量徽章、积分（无商城也可）
C. 契约完整体       多人、验收权等
D. 盈利专题         会员 →（可选）品牌券
E. 重合规能力       虚拟押金、公益资金（最后、单独关口）
```

滚动拆分见 [P6-product-backlog.md](../roadmap/phases/P6-product-backlog.md)。
