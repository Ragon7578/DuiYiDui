# 功能说明

## 核心流程

```
设定目标 → 绑定奖励 → 追踪进度 → 达成目标 → 兑现奖励
                                 ↘ 未达成 → 承诺作废，记录在案
```

---

## 1. 仪表盘（首页）

### 功能模块

| 区域 | 内容 |
|------|------|
| 欢迎语 | 显示用户名 + 当前信任分 |
| 统计卡片 | 总承诺数、已兑现、未兑现、信任分 |
| 进行中的目标 | 列出所有活跃状态的目标 |
| 最近的承诺 | 列出最近的契约记录 |

---

## 2. 目标管理

目标是整个平台的核心。每个目标包含：

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 目标标题 | 是 | 你要做到什么 | "瘦到 60 公斤" |
| 描述 | 否 | 补充说明 | "通过控制饮食和每周跑步 4 次" |
| 截止日期 | 否 | 什么时候完成 | "2026-12-31" |
| 奖励 | 是 | 达成后给自己什么 | "买一个包包" |
| 监督人 | 否 | 谁来见证 | 朋友、伴侣 |

### 目标状态流转

```
active（进行中）→ achieved（已达成）→ reward_claimed（奖励已兑现）
                → abandoned（放弃）
```

### 用户场景示例

> 小明说："如果我连续跑步 30 天，我就奖励自己一双新跑鞋。"
>
> 1. 他在平台创建目标：标题"连续跑步 30 天"，奖励"买一双 Nike 跑鞋"
> 2. 每天打卡记录进度
> 3. 30 天后达成目标，系统提示"恭喜！记得兑现你的奖励"
> 4. 小明买跑鞋，标记奖励已兑现
> 5. 信任分 +5

## 3. 契约管理

契约是 **与他人之间的约定**，比个人目标更正式。

### 契约 vs 目标的区别

| 维度 | 目标 | 契约 |
|------|------|------|
| 对象 | 对自己 | 对他人 |
| 约束力 | 自我约束 | 社交约束 |
| 奖励 | 自我奖励 | 双方约定 |
| 监督 | 自己/见证人 | 参与方互相监督 |

### 契约状态流转

```
draft（草稿）→ active（进行中）→ completed（已完成）
                                → breached（违约）
                                → cancelled（已取消）
```

### 条款状态

- **pending（待履行）** — 尚未完成
- **fulfilled（已履行）** — 已完成
- **breached（违约）** — 未履行

### 用户场景示例

> 小红和小李约定："如果小红帮小李完成设计稿，小李就请小红吃一顿大餐。"
>
> 1. 创建契约，双方参与
> 2. 条款：小红完成设计稿
> 3. 小红完成设计稿，标记条款已履行
> 4. 小李请吃饭，契约完成

## 4. 信任体系

### 信任分计算

```
基础分：50
+ 每完成一个目标 +5
+ 每履行一份契约 +10
- 每放弃一个目标 -5
- 每违约一次 -15
保底 0，封顶 100
```

### 展示

- 仪表盘顶部展示信任分
- 个人主页展示履约率、违约率可视化
- 信任分直接影响"你说的话有多少人信"

## 6. 导航栏

| 导航项 | 路由 | 说明 |
|--------|------|------|
| 契约精神 | `/` | 品牌名，点击回到首页 |
| 目标 | `/goals` | 目标列表（个人承诺 + 奖励） |
| 契约 | `/contracts` | 与他人的契约列表 |
| 创建 | `/create` | 创建新目标或契约（切换标签页） |
| 我的 | `/profile` | 个人主页 |

### 创建页（`/create`）

支持两种创建模式，通过标签页切换：

**目标模式**
| 字段 | 必填 | 说明 |
|------|------|------|
| 目标标题 | 是 | 你要做到什么 |
| 描述 | 否 | 具体计划 |
| 奖励 | 是 | 达成后奖励自己什么（核心字段） |
| 截止日期 | 否 | 什么时候完成 |

**契约模式**
| 字段 | 必填 | 说明 |
|------|------|------|
| 契约标题 | 是 | 约定名称 |
| 描述 | 否 | 详细内容 |
| 约定奖励 | 否 | 完成后的庆祝方式 |
| 参与方 | 是 | 添加多方参与人 |

## 用户体验关键点

### 创建目标时的心理设计

- **奖励必填** — 强迫用户想清楚"做到了能得到什么"
- **截止日期可选但推荐** — 没有截止日期的承诺容易无限期拖延
- **确认弹窗** — "你确定要放弃这个目标吗？这将影响你的信任分"

### 达成时的正向反馈

- 庆祝动画或提示
- 信任分增长通知
- 提醒兑现奖励

### 未达成时的处理

- 记录在案但不惩罚过度
- 显示"未完成"而非"失败"
- 鼓励重新设定
