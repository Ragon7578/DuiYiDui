# 功能规格

## 核心流程

```
设定目标 → 绑定奖励 → 追踪进度 → 达成 → 兑现奖励
                              ↘ 放弃 → 记录在案（影响信任分）
```

契约支线：创建 → 条款履约 → 完成 / 违约。

---

## 1. 账号与认证

| 能力 | 说明 |
|------|------|
| 注册 | 用户名 + 密码；不强制邮箱 |
| 登录 | 用户名 + 密码；JWT |
| 资料 | 「我的」可补邮箱、手机、简介 |
| 忘记密码 | 需已绑定邮箱；试验环境可返回重置链接 |
| 会话 | 前端 `cs_token`；业务 API Bearer |

---

## 2. 首页（仪表盘）

| 区域 | 内容 |
|------|------|
| 欢迎 | 用户名 + 信任分 |
| 统计 | 目标 / 契约相关计数 |
| 列表 | 进行中的目标与契约摘要 |

---

## 3. 目标管理

| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | 是 | 要做到什么 |
| 描述 | 否 | 补充计划 |
| 奖励 | 是 | 达成后给自己什么 |
| 截止日期 | 否 | 建议填写 |
| 见证人 | 否 | 邀请平台用户 |

**状态：** `active` → `achieved` → `reward_claimed`；或 `abandoned`。

**操作：** 更新进度、标记达成/放弃、兑现奖励、管理见证人（邀请 / 确认 / 拒绝）。

**场景：** 「连续跑步 30 天 → 新跑鞋」→ 进度 → 达成 → 兑现 → 信任分 +。

---

## 4. 契约管理

与他人约定；含参与方与条款。

| | 目标 | 契约 |
|--|------|------|
| 对象 | 自己 | 他人 |
| 奖励 | 自我奖励 | 双方约定 |
| 监督 | 自己/见证人 | 参与方 |

**契约状态：** draft / active / completed / breached / cancelled  
**条款状态：** pending / fulfilled / breached  

---

## 5. 承诺（Pledge）

轻量一句话承诺；有 API 与 `/pledges` 页，**主导航未挂载**（可从 URL 进入）。  
适合尚未形成完整「目标+奖励」时的记录。

---

## 6. 创建页

- Tab：目标 | 契约  
- 目标模式强调奖励必填  
- **语音输入**（浏览器 Speech API，视环境而定）  
- **智能填写**：调用 `POST /api/ai/parse` 解析自然语言  

---

## 7. 通知

- 列表、未读数、单条/全部已读  
- 类型含进度、见证、截止提醒等（以后端写入为准）  
- 导航显示未读角标  

---

## 8. 信任体系

| 事件 | 分数变化（实现） |
|------|------------------|
| 目标达成 | +5 |
| 目标放弃 | -5 |
| 契约履行 | +10 |
| 契约违约 | -15 |
| 默认 / 范围 | 50 起；约 0–100 |

展示：首页、我的（达成率/放弃率条）。

---

## 9. 个人主页

- 头像字、用户名（登录 id，资料接口不改名）  
- 编辑邮箱 / 手机 / 简介  
- 信任分与统计、目标记录列表  

---

## 10. 导航结构

| 项 | 路由 |
|----|------|
| 品牌 / 首页 | `/` |
| 目标 | `/goals` |
| 契约 | `/contracts` |
| 创建 | `/create` |
| 通知 | `/notifications` |
| 我的 | `/profile` |
| 登录 / 注册 | `/login` `/register` |
| 忘记 / 重置 | `/forgot-password` `/reset-password` |

---

## 11. UX 要点

- 奖励必填：逼用户想清回报  
- 放弃需意识到对信任分的影响  
- 达成后提醒兑现，形成闭环  
- 未达成记「放弃/未完成」，避免过度羞辱话术
