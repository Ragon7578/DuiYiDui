# 愿景

## 起源：一个普遍的问题

"如果我考上驾照，我就给自己买个 switch。"
"这个月业绩达标，我就去吃那家一直舍不得去的餐厅。"
"等这个项目上线，我一定要好好休息一周。"

这些话几乎人人都说过。**但绝大多数人从来没有兑现过。**

不是因为没有能力做到，而是因为：

1. **承诺太随意** — 说出口不需要成本，自然也不当回事
2. **没有记录** — 说过就忘，反正也没人记得
3. **没有追踪** — 目标达成的那天，奖励的承诺早已被遗忘
4. **没有监督** — 没人要求你对自己守信

这个项目的初衷很简单：**如果你对自己承诺了什么事情，就应该有一个地方把它记下来，然后真正做到。**

## 什么是契约精神？

契约精神不仅是商业社会的基石，也是个人自律的体现：

1. **承诺即契约** — 对自己说的话，也是对未来的自己的契约
2. **守信是习惯** — 从小承诺开始，逐渐建立守信的习惯
3. **奖励是正反馈** — 达成目标后获得奖励，形成正向循环
4. **违约有记录** — 不是惩罚，而是提醒自己曾经说过什么

## 为什么需要这个平台？

### 解决"说过就忘"

```
口头承诺 → 记录在平台 → 可追踪 → 可兑现
```

### 让奖励真正落地

```
"做到了就奖励自己" → 绑定具体奖励 → 达成后兑现 → 获得成就感
```

### 建立对自己的信任

每一次兑现承诺，都在积累对自己的信任。信任自己，才能信任他人。

## 设计理念

### 从自己开始

```
对自己守信 → 对他人守信 → 建立社会信任
```

先管好自己的承诺，再延伸到与他人的契约。

### 承诺 + 奖励 = 正循环

| 要素 | 作用 |
|------|------|
| 目标 | 明确你要做什么 |
| 奖励 | 给兑现承诺一个理由 |
| 记录 | 让承诺不可撤销 |
| 追踪 | 随时看到进度 |
| 兑现 | 完成目标，获得奖励 |

### 轻量、真实、不装

- 不需要复杂的法律条款
- 不需要严格的签署流程
- 只需要你对自己诚实

## 长远目标

- **个人层面** — 成为每个人的"承诺记事本"，帮自己兑现说过的话
- **社交层面** — 朋友间可以见证彼此的承诺，互相监督
- **文化层面** — 让"说到做到"重新成为一种值得骄傲的品质
